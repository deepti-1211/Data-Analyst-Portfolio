# Telecom Customer Churn Analysis

## Project Overview

An interactive Power BI dashboard developed to analyze telecom customer churn and identify key factors influencing customer retention.

The analysis focuses on customer demographics, contract types, tenure, internet services, payment methods, and churn patterns to generate meaningful business insights.

## Key Analysis

- Total Customers & Churned Customers
- Overall Churn Rate
- Churn by Contract Type
- Churn by Tenure
- Churn by Internet Service
- Churn by Payment Method
- Churn by Customer Demographics
- Identification of high-risk customer segments

## Tools & Skills

- Power BI
- Power Query
- Data Cleaning & Transformation
- DAX Measures
- KPI Development
- Data Visualization
- Interactive Dashboard Design

## Outcome

The dashboard provides a clear view of customer churn patterns and helps identify customer segments that may require targeted retention strategies.
