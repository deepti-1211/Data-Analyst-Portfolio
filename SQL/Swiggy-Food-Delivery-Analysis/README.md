# 🍽️ Swiggy Food Delivery SQL Analysis

## 📌 Project Overview

This project analyzes Swiggy food delivery data using **MySQL** to explore restaurant performance, ratings, delivery times, food types, and city-wise trends.

The project covers **data cleaning, data validation, and exploratory data analysis (EDA)**.

## 🛠️ Tools & Skills

* MySQL
* SQL
* Data Cleaning & Validation
* Exploratory Data Analysis (EDA)
* Aggregate Functions
* Subqueries
* Window Functions

## 🧹 Data Cleaning

The dataset was checked for:

* NULL values
* Duplicate records
* Invalid values
* Data consistency
* Extra spaces

Invalid price values were also handled during the cleaning process.

## 🔍 Key Business Questions

The analysis answers questions such as:

1. Which 5 cities have the highest number of restaurants?
2. What are the top 10 highest-rated restaurants?
3. Which restaurants have ratings above the overall average?
4. What is the highest-rated restaurant in each city?
5. Which 10 cities have the fastest average delivery time?
6. Which 10 areas have the highest number of restaurants?
7. Which cities have above-average delivery time?
8. What are the top 10 most common food types?

## 📊 SQL Concepts Used

`GROUP BY` • `HAVING` • `ORDER BY` • `COUNT()` • `AVG()` • `ROUND()` • `SUM()` • Subqueries • `RANK()` • Window Functions • `PARTITION BY`
